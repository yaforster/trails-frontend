`TestPlanModellerGraphService` is the single persistence boundary for the editable graph and serialized test-plan
definition. It validates unique references, resolved edges, acyclicity, and exactly one start action before submission.
`TestPlanGraphValidationService` supplies server graph limits from startup capabilities; the graph validator counts
paths and total action occurrences before allowing save, without expanding execution paths.

The run dialog owns completion-email opt-in and recipient validation; disabled notification is omitted from requests.
The SDK remains authoritative. `api/hateoas.yaml` mirrors the SDK contract, and all files under
`src/app/generated` are generated by `scripts/generate-api.mjs` and must not be edited.
